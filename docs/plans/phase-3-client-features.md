# Phase 3: Client Features

## Goals
- Port and modernize features from the Ionic reference app to the PHP-based Client Area.
- Ensure a seamless, mobile-first responsive experience.

## Tasks
1. **Client Dashboard (`/client/index.php`)**
   - User-specific overview (Personal details, recent notifications).
   - Quick access links to major features.

2. **Notifications System**
   - View list of society-wide and personal notifications.
   - Mark as read functionality.

3. **Personal Profile Management**
   - View and update contact information.
   - Change password / Setup PIN.

4. **Document Uploads**
   - Interface for residents to upload identity documents or society-related files.
   - File validation (size, type) and secure storage.

5. **Responsive UI refinement**
   - Ensure all client pages work perfectly on mobile browsers.
   - Implement "Pull to refresh" simulation using JS where applicable.
