# References

This directory contains design reference materials, screenshots, and prototypes for the SocietyApp project.

## Directory Structure

- **`draft/`**: Contains active design reference materials, draft captures, prototypes, and screenshots (`draft/Screenshots/`). All files within this directory are intentionally excluded from Git tracking (via `draft/.gitignore`) so they remain local without bloating the repository.

## Scripts

To generate or update reference screenshots locally in `references/draft/Screenshots/`:
```bash
npm run screenshots
```
